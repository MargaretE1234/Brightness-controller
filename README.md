💡 LED Brightness Control with Shift Register

This project uses a shift register to control eight LEDs and turn them on or off using push buttons. The LEDs represent different levels of brightness, with more LEDs being turned on as the brightness level increases.

The **up button** increases the brightness by turning on more LEDs, while the **down button** decreases the brightness by turning off LEDs. The shift register allows the Arduino to control all eight LEDs using fewer output pins.

This project demonstrates how shift registers can be used to expand the number of outputs available on a microcontroller and can be used to simulate brightness control on a computer.

 🧰 Components Used

* Arduino Uno
* Shift Register
* 8 LEDs
* Push Buttons
* Resistors
* Breadboard
* Jumper Wires
